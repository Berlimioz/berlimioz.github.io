# berlimioz.fr

Site personnel de Chloé Roger : profil public + journal d'apprentissage de l'ingénierie LLM.

- **Stack** : Jekyll (design maison « tokens »), hébergé sur GitHub Pages, domaine `berlimioz.fr`
- **Écrire un billet** : un fichier markdown dans `_posts/` nommé `AAAA-MM-JJ-titre.md`, puis commit + push — GitHub Pages reconstruit tout seul
- **Prévisualiser en local** : `bundle install` puis `bundle exec jekyll serve` → http://localhost:4000

⚠️ Contenu public : jamais d'informations administratives ou personnelles
(la version privée du suivi vit dans `~/_PROJETS/Formation IA/SUIVI.md`).

L'ancien site Rails (2019-2023) est archivé dans `../berlimioz_old`.
