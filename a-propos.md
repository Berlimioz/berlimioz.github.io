Je suis **Chloé Roger**, développeuse web fullstack senior basée à Paris.
Je code professionnellement depuis 2010, principalement en **Ruby / Ruby on Rails**.

## Parcours

Pendant douze ans chez **Mipise** (plateforme SaaS de crowdfunding), j'ai conçu
et maintenu l'architecture des **flux financiers de l'établissement de
paiement** : des systèmes critiques où un bug se compte en euros, dans un
cadre réglementé (DSP2).

Avant cela : dix ans de développement web fullstack, du e-commerce (Solidus)
aux applications métier. Côté open source : contributions e-commerce
(`open_solidus_cloudinary`), moteur de rendu Markdown (`marksila`),
Arctic Code Vault Contributor.

## Aujourd'hui : l'ingénierie LLM

Je consacre plusieurs mois à une montée en compétence structurée sur les
LLM, avec un angle précis : **le déploiement et le self-hosting de modèles
en production** — inférence, quantification, RAG, observabilité. Le
programme complet est public, et chaque avancée est consignée dans le
[journal](/) de ce site.

Trois projets en sortiront, publiés sur [GitHub](https://github.com/Berlimioz) :

1. un mini-GPT entraîné from scratch, expliqué en français ;
2. une application RAG sur un corpus réglementaire paiement/DSP2 —
   là où mon expérience fintech rencontre l'IA ;
3. une API d'inférence self-hostée : modèle fine-tuné, dockerisé,
   monitoré, benchmarké.
